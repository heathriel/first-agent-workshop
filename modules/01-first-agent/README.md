# Module 1 — Your First Agent: A Goal and a Boundary

An agent is an LLM that runs tools in a loop to achieve a goal. That's it. That's
the secret. Everything else this morning is seatbelts and job descriptions.

## Triage your excavated task first
- Same steps every time → you want a script or a Zap. (That's a compliment, not a loss.)
- Steps vary, but "done" is checkable → **agent. Continue.**
- "Done" isn't checkable → keep doing it yourself (for now).

## Exercise
1. Open [`JOB_DESCRIPTION.md`](JOB_DESCRIPTION.md) and fill in the blanks —
   your excavated task, one boundary, and (BEFORE anything else) the check.
2. Paste the completed job description into your agent as its instructions.
3. Ask it to do the job. ✅ **Check 1:** it produces your proof-of-done.
4. Now ask it to do the thing you forbade. ✅ **Check 2:** it refuses.
5. Try to talk it past the boundary. Politely. Deviously. Note what works —
   we'll talk about why at 9:55.
