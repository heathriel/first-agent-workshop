# Any assistant: browser/manual lane

No terminal or native skills are required to practice the reasoning. Use only the fictional data.

1. Open data/meeting.txt on GitHub. Paste its text and the Module 1 prompt into your assistant. Copy returned JSON to a local file if possible; otherwise compare all fields manually with the source.
2. For memory, save your rules and fictional facts in a local document. Start a fresh chat and explicitly supply it. This demonstrates persisted, reloaded context; it is not automatic file discovery.
3. Paste your completed SKILL.md followed by the transcript and ask it to apply the procedure. This is explicit prompt reuse, not native skill registration. A pasted transcript is not an MCP tool call.
4. Act as the loop controller: inspect the result, return the error, stop after three attempts. Record a missing-owner escalation.
5. Use separate chats for Worker A, Worker B, then reviewer after both, then lead synthesis. Copy evidence between chats deliberately.

Save the contract and output. If no local files can be created, use a document you control. Pair with a terminal user for executable checks. Never report a manual comparison as an automated PASS or a scripted rehearsal as a live model run.
